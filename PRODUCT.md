# Newsland
<!-- impeccable:product-schema 1 -->
## Platform
web
## Users
Personal use by an Indian trader preparing for today's session and the coming week.
## Product Purpose
Reduce time spent reading multiple publications by grouping and filtering market events.
## Capabilities and Constraints
Free sources, auto refresh, global and India drivers, scheduled catalysts. Telegram digests deferred until product is satisfactory. Never invent news or calendar times. Minimal interface requested. Desktop project requested.
## Stack
Implementation choice: dependency-free Python server with HTML/CSS/JavaScript. Local-first delivery inferred from Desktop request.
## Open decisions
Personal watchlist; verified event-calendar data source; relevance quality to be evaluated over trading days.
